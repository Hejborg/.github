## Why “Hejborg”?
Hej is Swedish for “hello”: robots should be easy to say hello to, which is the idea behind plug-and-play. Borg means fortress, and it hints at cyborg: the point where AI meets a physical machine. The name stands for a friendly interface with a strong foundation underneath, real-time control that is predictable and robust.
And... You know Borg from StarTrek, right?
